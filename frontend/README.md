# AI Buddy: фронтенд

Интерфейс стажёра: вход, «Главная» и «AI-чат». Бэкенд ещё не подключён — все данные идут из заглушек в `src/api/`.

Стек: React 19, TypeScript, Vite 8, шрифт Inter (`@fontsource-variable/inter`).

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev
```

Откроется http://localhost:5173. Сборка: `npm run build`, результат в `dist/`. Проверка типов — `npx tsc -b`, линт — `npm run lint`.

## Устройство

- `src/App.tsx`: переключение экранов (вход → главная ↔ чат).
- `src/Login.tsx`, `src/Home.tsx`, `src/Chat.tsx`: экраны.
- `src/Shell.tsx`: боковая панель и вкладки.
- `src/ui.tsx`: иконки, логотип, аватар, маскот.
- `src/index.css`: токены, размеры, цвета, анимации и адаптив.
- `src/api/client.ts`: **единственное место, где будет сеть**. Сейчас функции возвращают данные из `mock.ts` с искусственной задержкой.
- `src/api/types.ts`: контракты (`User`, `ChatMessage`, `HomeData`, …).
- `public/icons/`: SVG-иконки из макета (`01-email.svg` … `20-hr-calendar-blue.svg`, `avito-mark.svg`).
- `public/img/`: логотип и три маскота PNG с прозрачным фоном.

Вёрстка адаптивная и не привязана к координатам макета: две колонки на десктопе, одна на планшете, горизонтальная панель на телефоне.

### Иконки

Файлы в `public/icons/` используются как CSS-маска (`Icon` в `src/ui.tsx`), поэтому цвет задаётся через `currentColor`. Исходные заливки внутри SVG игнорируются — это позволяет красить одну и ту же иконку в белый на цветных кружках и в тёмный в тексте.

## Подключение бэкенда

Все запросы собраны в `src/api/client.ts`. Сигнатуры менять не нужно — достаточно заменить тела функций на `fetch`:

| Функция | Будущий эндпоинт |
| --- | --- |
| `login()` | `POST /api/auth/login` |
| `fetchMe()` | `GET /api/me` |
| `fetchHome()` | `GET /api/home` |
| `fetchHistory()` | `GET /api/chat/messages` |
| `sendMessage(text)` | `POST /api/chat` (желательно SSE-стрим) |

Пока эндпоинтов нет, `sendMessage` возвращает фиксированный текст-заглушку `BUDDY_REPLY`.

## Отладка

- `?s=main` или `?s=chat` открывает экран сразу, без входа.
- Исходные кадры макета лежат в `public/ref/` (`p1`–`p3`) для сверки глазами.
