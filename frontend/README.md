# AI Buddy: фронтенд

Интерфейс стажёра по финальным экранам: вход, «Главная» и «AI-чат». Данные пока статичные, к API не подключено.

Стек: React 19, TypeScript, Vite 8. Шрифт Inter (`@fontsource-variable/inter`), иконки Lucide и Phosphor.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev
```

Откроется http://localhost:5173. Сборка: `npm run build`, результат в `dist/`.

## Устройство

- `src/App.tsx`: переключение экранов (вход → главная ↔ чат).
- `src/Login.tsx`, `src/Home.tsx`, `src/Chat.tsx`: экраны.
- `src/Shell.tsx`: боковая панель и вкладки.
- `src/ui.tsx`: холст `Stage`, логотип, аватар.
- `src/index.css`: все размеры, цвета и анимации.
- `public/img/`: маскот (WebP с прозрачным фоном).

Экраны свёрстаны в координатах исходного макета (кадр главной 1086 × 600) и целиком масштабируются под окно, общим масштабом для всех экранов.

## Отладка

- `?s=main` или `?s=chat` открывает экран сразу, без входа.
- `?ov=diff` накладывает исходный кадр из `public/ref/` для сверки, `?ov=0.5` делает то же полупрозрачно.
- `?fixed` выставляет масштаб 1.
