# Команда Авито Путешествий

## Чем занимается команда

Команда отвечает за краткосрочную аренду жилья на Авито: поиск вариантов по датам и количеству гостей, карточку объекта, календарь занятости, бронирование и переписку гостя с хозяином. Главная метрика команды — доля успешных бронирований от просмотров карточки.

Чтобы понять продукт, пройди путь пользователя сам: найди жильё на выходные, открой карточку, выбери даты и дойди до экрана подтверждения бронирования (оплачивать не нужно). Это задача «Обзор продукта Путешествий» из твоего чек-листа.

## Стек

- Бэкенд: Go, PostgreSQL, Redis для кэша поисковой выдачи, Kafka для событий бронирования.
- Поиск по датам и гео — отдельный сервис поверх Elasticsearch.
- Фронтенд: React и TypeScript.
- Сервисы разворачиваются в PaaS Авито, мониторинг — Grafana, логи — в общей платформе логирования.

## Репозитории и доски

- Код лежит в GitLab в группе `travel`. Для работы нужна роль developer — её выдаёт наставник после заявки на доступ к GitLab.
- Основные репозитории: `travel-search` (поиск), `travel-booking` (бронирования), `travel-web` (фронтенд).
- Доска команды в Jira — проект `TRVL`. Стажёрские задачи помечены меткой `intern`.
