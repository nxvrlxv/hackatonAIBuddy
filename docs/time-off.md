# Отгул: MVP

Go владеет БД, Flask вызывает MCP. Автор определяется по Bearer JWT, а не по аргументам модели.
Миграция 0005_requests добавляет buddy.request_types и buddy.requests.
Тип time_off: start_date/end_date (YYYY-MM-DD, целые дни включительно), reason (необязательная, до 2000 символов).
Начало не раньше текущей даты по Москве; конец не раньше начала.
Шаблон в БД описывает форму и доступность типа. Правила time_off реализованы в Go;
изменение fields не добавляет новые обработчики и не меняет автоматически Go-валидацию.

## API Go

Все ручки требуют Authorization: Bearer <JWT>.
- GET /api/request-types — доступные типы и поля.
- GET /api/requests — последние 100 собственных заявок.
- POST /api/requests/time-off — start_date, end_date, reason, idempotency_key.
Ответ 200: id, type_code, data, status, created_at. Ошибки: 422 — данные, 409 — конфликт.
Идентичный повтор возвращает исходную запись; другой payload с тем же ключом — 409.
Одинаковый диапазон активной заявки нельзя создать второй раз. Частично пересекающиеся диапазоны пока допускаются.

## MCP и агент

get_request_types, create_time_off_request, list_my_requests.
Перед созданием агент получает требования и уточняет отсутствующие даты.
На «как оформить отгул?» объясняет порядок без создания.
На «оформи отгул на ...» создаёт без отдельного подтверждения.
Агент подставляет ключ time-off:<run_id> сам; LLM его не выбирает.
Один ход предназначен для одной заявки. Исправленные данные после ошибки можно отправить следующим сообщением.
Статус submitted означает только запись заявки, не одобрение.
Уведомлений и процесса согласования пока нет. Checkpointer/interrupt не подключены.
Инструменты заявок доступны в go-режиме; автономное RAM-демо их не поддерживает.

## Запуск и проверка

Из корня: docker compose up -d --build api mcp-buddy agent
Мигратор применяет 0005, HTML-демо доступно на http://localhost:8001/demo.
Из agent: PYTHONPATH=src .venv/bin/python tests/smoke_requests.py
Проверка создаёт явно помеченную тестовую заявку и оставляет её в БД.
Примеры диалогов: «Как оформить отгул?», «Оформи мне отгул» (ожидается уточнение),
«Оформи отгул на 20 ноября 2026 года», «Покажи мои заявки».
Для повторения примеров выбирайте будущие даты.
